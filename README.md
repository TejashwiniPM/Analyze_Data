## 🚀 Key Features

- **Automated KPI Dashboard**: Instant executive overview featuring verified numerical KPIs, dynamic chart recommendations, and segment trends.
- **Statistical Analysis**: Descriptive statistics, distribution percentiles (p25, p50, p75, p90), outlier detection (IQR), and Pearson correlation matrices.
- **Data Quality Profiling**: Rigorous column-by-column hygiene analysis, missing values audit, duplicate row detection, and data type inference.
- **Ask My Data (Fact-Grounded NLQ)**: Natural language queries backed by a deterministic math calculation engine before AI explanation.
- **Interactive Dataset Explorer**: High-performance tabular data grid with multi-column sorting, search filters, and CSV export.
- **Executive Management Reports**: Board-ready automated synthesis reports with print/PDF styling.
- **White Lilac & Dark Blue Dual Themes**: Fully WCAG AAA/AA compliant high-contrast visual themes with smooth transitions.

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons
- **Charting & Data Viz**: Recharts
- **Data Parsing & Profiling**: SheetJS (`xlsx`), PapaParse, Lodash
- **Server**: Express.js with Vite middleware
- **Build System**: Vite
